# Financial Analysis & Power BI Dashboard

## 📊 Project Overview

This project demonstrates an end-to-end financial data analysis workflow, from working with messy/raw data to cleaning, transforming, analyzing, and presenting insights through an interactive Power BI dashboard.

The project was completed using **Microsoft Excel** and **Microsoft Power BI**, with **Power Query** used for data cleaning and transformation.

The main objective was to transform raw financial data into a structured dataset and develop an interactive dashboard that makes financial performance easier to understand and analyze.

---

## 🎯 Project Objectives

The key objectives of this project were to:

- Clean and organize messy financial data.
- Use Excel for initial data cleaning and preparation.
- Import the raw dataset into Power BI.
- Use Power Query for additional data cleaning and transformation.
- Organize the data for analysis.
- Analyze financial performance across different dimensions.
- Create meaningful KPIs and visualizations.
- Build an interactive Power BI dashboard.
- Present financial information in a clear and professional format.

## 🔄 Data Analysis Workflow

### 1. Initial Data Cleaning with Excel

I first worked with the raw/messy dataset in Microsoft Excel.

The initial cleaning process included organizing the dataset and preparing the information for analysis.

The purpose of this stage was to understand the structure of the data and identify issues that needed to be addressed before visualization.

---

### 2. Data Cleaning with Power Query

After the initial Excel work, I imported the messy/raw dataset into Power BI.

I then used **Power Query** to further clean and transform the data.

This stage involved:

- Cleaning the dataset
- Organizing columns
- Correcting data types
- Transforming data where necessary
- Preparing the dataset for analysis
- Structuring the data for effective visualization

Power Query allowed me to create a more organized and analysis-ready dataset before building the dashboard.

---

### 3. Data Analysis

After cleaning and organizing the data, I analyzed financial performance across several dimensions, including:

- Country
- Segment
- Product
- Year
- Month
- Quarter

This allowed me to examine how profit changed across different categories and time periods.

---

### 4. Dashboard Development

I created an interactive Power BI dashboard to present the results.

The dashboard includes key performance indicators such as:

- Profit by Country
- Profit by Segment
- Profit by Product
- Profit by Year
- Profit by Month
- Profit by Quarter

It also includes interactive filters for:

- Country
- Year

These filters allow users to explore the financial data dynamically.
